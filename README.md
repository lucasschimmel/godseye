# G.O.D.S.E.Y.E

Private hosting and operations platform for managing applications, isolated project
backends, deployments, durable jobs and agent-assisted operations.

The project is in local development. The complete source and implementation guides
live on the [`develop`](https://github.com/lucasschimmel/godseye/tree/develop) branch. This `main` branch is reserved
for explicitly approved releases and currently contains this presentation only.

The target stack includes React, TanStack, TypeScript, Bun, PostgreSQL, Inngest and
Hermes. Dedicated-server installation and production qualification are still ahead.
