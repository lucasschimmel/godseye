# G.O.D.S.E.Y.E visual direction

An infrastructure atlas for one operator. Dense, calm and legible; a service inventory rather than a marketing hero. A dark maritime navigation rail surrounds a pale mineral work surface. Teal indicates primary actions, amber indicates qualification/pending attention. Status always includes words, not color alone.

Palette: navigation #12232f / #0d1720, canvas #edf0ed, surface #ffffff, accent #147b80, attention #98631a. Semantic CSS variables own all component colors in `apps/console/src/styles/theme.css`; components consume roles such as `--text-primary`, `--surface`, `--accent-ink` and `--attention-surface`. Body typography uses Segoe UI/system sans, restrained display typography uses Bahnschrift/Aptos Display, and utility metadata uses Cascadia Code/system monospace. Local fonts can replace these without component edits.

Signature: a small concentric eye mark and a live environment strip that distinguishes this local workstation from connected hosts. No decorative resource charts with invented observations. Responsive navigation, visible focus, useful empty/error/loading states and reduced motion are required.
