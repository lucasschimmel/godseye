## Independently reproduced and resolved finding

### DGT-001 — mutable installation authority during source lookup

- **Initial result:** 94/95 pass, one failure. While `GithubAppSourceProvider.resolve` awaited an original installation lookup, a controlled callback changed the caller's repository/installation/query objects. The next repository lookup requested authentication for the substituted installation before validating the original proof. Returning a final unavailable error did not undo that foreign private-auth request.
- **Behavioral oracle:** `T-AC-44 never returns substituted source authority when caller bindings change during lookup` accepts either exact original evidence or a safe bounded source-unavailable denial, while requiring every private lookup to retain the original installation ID. It does not require a successful result when safe denial is possible.
- **Producer correction:** snapshot binding and query before the first await; subsequent derived API paths and private-auth lookups use that detached scope.
- **Independent verification:** unchanged test passes; the full 95-case policy/source slice passes. No production edits were made by GAUNTLET.
- **Status:** resolved by executable regression. This is a local source-adapter fault test, not live GitHub App qualification.

- Strict private Zod evidence rejects truthy strings in successful checks/readiness/isolation claims; successful JSON/process exit alone is insufficient.
- Streamed GitHub responses enforce bytes rather than UTF-16 character count; zero PR head SHAs are denied.
- Provider promotion receives the exact previous immutable scope, allowing actual transport ownership lookup without a private database resolver.
- Retained artifacts must satisfy the current policy's additional trusted checks and configuration before release/rollback.
- Exact read-only cleanup reconciliation reaches closing/expired previews without relaxing recovery HOLD; ordinary unknown preview reconciliation still enforces current policy/head/cell authority.
- Actual first-party source composition projects only the strict branch/PR query; a permissive synthetic source fixture cannot conceal extra-field rejection.
- Terminal Foundation settlement rechecks authority after runtime evidence was recorded. Revocation in that gap leaves unknown state/capacity instead of committing activation or crashing the worker.
- Protective TTL cleanup survives missing source configuration/revoked policy, retains the original provider binding and cannot free a retargeted namespace through foreign absence.
- Public 128-character synchronization keys derive bounded hashed child keys and durably replay the same preparation.
